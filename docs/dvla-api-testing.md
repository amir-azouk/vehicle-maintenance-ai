
# DVLA Vehicle Enquiry Service API Testing

## Objective
Test the DVLA VES API and establish whether it can retrieve vehicle-specific information using a registration number.

## Test results
- API connection: Successful
- Authentication: Successful
- Python integration: Successful
- Multiple registration tests: Successful

## Retrieved fields
- Registration number
- Tax status and due date
- MOT status and expiry date
- Make
- Year of manufacture
- Engine capacity
- CO2 emissions
- Fuel type
- Export status
- Colour
- Type approval
- Euro status
- Date of last V5C issued
- Real Driving Emissions
- Wheelplan
- Month of first registration

## Limitations
The DVLA VES API provides vehicle identification and recorded status information. It does not provide confirmed mechanical fault diagnoses, detailed MOT defect history or verified repair outcomes.

## Conclusion
The DVLA VES API can successfully provide vehicle-specific information for the vehicle profile component of the application.
